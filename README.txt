FUELPOINT PETROL STATION WEBSITE
================================

This ZIP contains an 8-page responsive website:
1. index.html - Home
2. about.html - About Us
3. fuel.html - Fuel Services
4. services.html - Vehicle Services
5. shop.html - Convenience Shop
6. safety.html - Safety & Environment
7. offers.html - Offers
8. contact.html - Contact

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html.
4. Right-click and choose "Open with Live Server" (if the Live Server extension is installed),
   or double-click index.html to open it in your browser.

IMPORTANT CUSTOMISATION
- Replace FuelPoint with your real petrol station name.
- Update the sample phone number, email, address and opening hours.
- The images load from Unsplash, so an internet connection is needed to display them.
- The contact form is a front-end demo; connect it to a backend or form service to receive messages.
- Confirm actual fuel prices and promotions before publishing.
